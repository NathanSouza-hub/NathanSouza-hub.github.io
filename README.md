# Portfólio · Nathan Souza

Site pessoal de Nathan Souza, desenvolvedor full stack júnior e estudante de Engenharia da Computação.

**No ar:** https://nathansouza-hub.github.io/

HTML, CSS e JavaScript puros, sem build e sem dependências.

## Estrutura

- `index.html`: conteúdo e meta tags
- `style.css`: estilos e tema claro/escuro
- `script.js`: lista de projetos, faixa de tecnologias, menu e animações
- `img/`: capturas de tela dos projetos e imagem de compartilhamento

## Adicionar um projeto

Inclua um item no array `projetos` em `script.js`. Com `imagem` preenchida, o card vira destaque (largura total). Com `academico: true`, ele entra na lista compacta de trabalhos acadêmicos.

## Rodar localmente

Abra o `index.html` no navegador.
